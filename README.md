# LUNARA GLOBAL v0.1

A responsive, installable-ready global calendar prototype.

## Included
- Responsive calendar month view
- Dark / light theme
- 8 interface languages: English, Vietnamese, Spanish, French, German, Japanese, Korean, Chinese
- Create and delete events
- Events and language preference saved locally in the browser
- No login and no analytics

## Run
Open `index.html` in a modern browser, or publish the folder to GitHub Pages / any static web host.

## Important v0.1 limitations
- Event storage is local to the current browser/device. Cloud sync is not implemented.
- This version uses the Gregorian calendar. Localized public holidays, regional calendars, lunar calendar conversion, reminders and timezone-aware event scheduling are planned for later releases.
- The app requires HTTPS or localhost for full install/PWA behavior on most browsers.
