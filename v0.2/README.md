# LUNARA GLOBAL v0.2 (preview)
Separate preview build. The v0.1 root files are not included or modified.

## Included
- Month / week / day calendar views
- Selectable starter holiday lists for Vietnam, US, UK, Japan, France, Germany, South Korea and China
- Create/delete events, stored locally in this browser
- Optional reminder while the app is open; browser notification permission may be requested
- Eight language choices; Vietnamese and English have complete interface translations in this preview
- Dark / light theme

## Important limitations
- Holiday data is a small fixed-date starter set, not a complete official calendar. Variable-date, lunar and regional holidays are not included.
- Vietnamese lunar conversion is not yet enabled in this preview; the app explicitly labels this as pending rather than showing an unverified date.
- Reminders are checked while the page is open. A static GitHub Pages site cannot guarantee alerts when the browser is closed or suspended.
- Events remain on the current browser/device. Cloud sync is not enabled.
