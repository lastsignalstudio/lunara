# LUNARA GLOBAL v0.4.1 — Country Visual Experience

## What changed
- Country selection updates the visual identity across the full interface, not just the flag or country label.
- The hero, country artwork, page atmosphere, calendar panel, agenda, event cards and event modal use the selected country's visual scene and palette.
- Includes locally embedded vector illustrations for Vietnam, United States, United Kingdom, Japan, France, Germany, South Korea, China, Australia, Canada, India and Brazil.
- No third-party image requests are required for the country artwork.
- The existing v0.4 calendar engine and styles are reused from `../v0.4/` to preserve the current calendar and event behavior.

## Upload
Upload all six files in this folder into a new folder named `v0.4.1` at the repository root:
- index.html
- country-theme.js
- country-theme.css
- manifest.webmanifest
- sw.js
- README.md

Do not upload these files into the repository root and do not overwrite `v0.4`.

## Important
This release is a public preview. Country holiday labels are illustrative and are not a complete official holiday database. Test the site after GitHub Pages deploys. If an older cached view appears, close the tab and reopen the URL; the new service-worker cache uses a v0.4.1 name.
