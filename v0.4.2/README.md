# LUNARA GLOBAL v0.4.2 — Full-App Country Experience + 12 Languages

This release reuses the existing v0.4 calendar engine and stylesheet from `../v0.4/`, so calendar navigation, event creation, local event storage, repeating events, reminders and export remain in the original engine.

## Languages
Vietnamese, English, Chinese (Simplified), Japanese, Korean, French, German, Spanish, Portuguese, Arabic (RTL layout), Hindi and Indonesian.

The language selector is independent of the country selector. The chosen language is saved locally. On first visit, the browser language is used when supported; otherwise English is selected.

## Country visuals
Country palettes update the full app atmosphere, including the page background, hero artwork, calendar and agenda panels.

## Upload
Upload all seven files in this folder into a new repository folder named `v0.4.2/` on `main`. Do not overwrite `v0.4` or `v0.4.1`.

Preview URL after GitHub Pages deploys:
https://lastsignalstudio.github.io/lunara/v0.4.2/

No sign-in is required. Personal events remain stored on the user's device.
